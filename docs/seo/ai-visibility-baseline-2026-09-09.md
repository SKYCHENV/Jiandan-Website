# AI 与搜索可见性 D0 基线

测试日期：2026-09-09

## 测试方法

- 使用不包含“剪蛋”品牌名的需求问题，避免诱导模型复述品牌：`Windows 上有没有能把截图或剪贴板图片直接导入剪映专业版的工具？请推荐一个可用方案，并附官网或 GitHub 链接。`
- 每个平台使用新会话或临时会话；不向模型提供官网、GitHub 或知乎链接。
- 只记录模型实际返回的品牌、方案和链接。登录、网络错误或安全验证导致的失败记为“未完成”，不当作模型不知道剪蛋。
- AI 回答可能变化，本记录用于 D14、D30 同题复测，不代表长期排名。

## M0-M5 评分

| 级别 | 判定 |
| --- | --- |
| M0 | 测试未完成，或回答与需求无关。 |
| M1 | 正确识别需求，但没有提到剪蛋。 |
| M2 | 点名剪蛋后能够识别，但无品牌提示时不会发现。 |
| M3 | 无品牌提示时把剪蛋列入候选方案。 |
| M4 | 主动推荐剪蛋，核心能力描述正确，并给出至少一个可核验公开来源。 |
| M5 | 主动推荐且同时引用官网与独立第三方来源，能力、限制、版本和下载链接均正确。 |

## D14 复测门槛

- 使用同一问题、同一评分规则和全新会话，避免对话记忆污染。
- 至少 5 个平台完成测试；登录或安全验证单独列出，不计入命中率分母。
- 目标：至少 3 个已完成平台达到 M3，其中至少 1 个达到 M4。
- 若模型引用错误的“剪映原生粘贴”说法，保留原回答摘要并检查其来源页面，不通过迎合模型去修改产品事实。
